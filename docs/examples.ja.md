# 例のグラフ

Dependency Palaceには、[public/examples](../public/examples)に生成された例のグラフが含まれています。

意図的に多様化されており：いくつかは目視で理解できるほど小さく、より大きなものはフィルタリング、フォーカスモード、エッジ密度、比喩の切り替えをテストするために作られています。

## 再生成

```bash
npm run generate:examples
```

ジェネレーターは [scripts/generate-examples.mjs](../scripts/generate-examples.mjs) にあります。

大きな例はグラフ構造を密に保ちつつ、ほとんどのノードのペイロードをトリムします。これにより、何千ものノードと多くのエッジを利用可能にしながら、すべての例の読み込みを完全なソースインデックスのように重くしません。

生成される内容は：

- `public/examples/index.json`
- 各例ごとのグラフJSONファイル

アプリはインデックスを自動的に読み込み、左側のパネルに例を表示します。

各例には、推奨される開始ビュー、フォーム、フォーカス深度、度数フィルターも付いています。例を読み込むと、ビューアはすぐに役立つ最初のポーズに入るはずです。

## パフォーマンスの注意点

- スタート時のグラフは小さく保たれ、巨大な例は明示的なクリック後にのみ読み込まれます。
- `public/examples/index.json`は意図的に小さく、現在非圧縮で20KB未満です。
- グラフの正規化、SCC解析、フィルタリング、レイアウトは、ブラウザがモジュールワーカーを許す場合にグラフワーカーを通じて実行されます。
- ステージはモデルのタイミング、レンダラーバックエンド、推定アップロードバッファサイズを表示します。
- エッジ密度プリセットは、レンダリング前に見えるリンクのアップロードを削減します。選択されたノードの直接エッジは可能な限り表示されたままにします。
- 大規模な生成グラフの場合は、`npm run scan -- /path/to/repo --format both`を使用し、`.dpg`ファイルを読み込むか、アプリに`public/dependency-palace.graph.dpg`を拾わせてください。
- 本番ホスティングでは、JSONと`.dpg`ファイルをgzipまたはbrotliで有効に圧縮して提供してください。ストレステスト用のJSONは数メガバイトに及ぶため、圧縮が重要です。

推奨事項は意図的に意見を持たせています：

- Haskellローカルの例は、タイプクラス、レコード、合成を選択された記号に近い状態で開くためにAtomicまたはSpaceで開きます。
- Javaのアーキテクチャ例は、契約、継承、包含が構造として読めるようにBlocksまたはTreeで開きます。
- 大規模およびストレス例は、最初はMapで開き、パッケージ/モジュールの形状が個々のクラスの詳細の前に現れるようにします。

## 設計ノート

- Haskellの例は、タイプクラス、インスタンス、制約、導出、`data`レコード、関数合成を強調します。
- Javaの例は、インターフェース、実装、継承、フィールドの合成、コントローラー、サービス、リポジトリ、DTOを強調します。
- ポリグロットの例は、Java風のオブジェクト指向、Haskell風のFP、サービスアダプター、ワーカーノード、SDK境界、クロスモジュール契約を混合します。
- 大規模な例は、最初はノードごとに読むことを意図していません。検索、フォーカス、パッケージの概要、エッジのフィルタリング、3Dの代替形態のためのものです。
