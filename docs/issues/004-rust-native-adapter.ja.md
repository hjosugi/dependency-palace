# ネイティブアダプター：Rust

ラベル：`adapter`、`rust`、`priority:P1`、`status:ready`

## 問題点

Rustの構造体は、モジュール、トレイト、implブロック、マクロ、機能、クレートによって構成されています。最初のパースャは構造体やトレイトを表示できますが、ネイティブな正確さにはRustのツールが必要です。

## 候補バックエンド

- `rust-analyzer`の解析データ。
- ワークスペース/クレートのグラフのための`cargo metadata`。
- ソースのフォールバック用に`syn`ベースのパーサ。

## 必要な抽出項目

- クレート、モジュール、ファイル。
- 構造体、列挙型、トレイト、トレイトエイリアス。
- フィールド、関連関数、メソッド。
- `impl Trait for Type`を実装として認識。
- 固有のimplメソッド。
- `use`によるインポートとクレート依存関係。
- 利用可能な関数呼び出し。
- マクロ展開の診断や、最善のマクロ境界。

## 受け入れ基準

- Cargoワークスペースで動作すること。
- `crate::module::Type`のような安定したIDを出力。
- トレイト実装を正しくリンク。
- レシーバーメソッドと関連関数をキャプチャ。
- 解決できないマクロ生成シンボルをクラッシュせずに報告。
