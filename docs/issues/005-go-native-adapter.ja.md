# ネイティブアダプター：Go

ラベル：`adapter`、`go`、`priority:P1`、`status:ready`

## 問題点

Goはパッケージ認識型のシンボル解決を必要とします。構造体、インターフェース、レシーバーメソッド、埋め込みフィールド、モジュールのインポートには`go/packages`または同等のツールが必要です。

## 候補バックエンド

- `golang.org/x/tools/go/packages`
- `go/types`
- モジュール/パッケージの探索に`go list`

## 必要な抽出項目

- モジュールとパッケージ
- 構造体とインターフェース
- フィールド、埋め込みフィールド、レシーバーメソッド
- 推測可能な場合のインターフェースの満足度
- インポートとパッケージ依存関係
- `via`を伴う関数/メソッド呼び出し
- コンストラクターのような複合リテラル

## 受け入れ基準

- Goモジュールとワークスペースで動作する
- `module/path/pkg.Type`のようなIDを出力
- 所有タイプに対するレシーバーメソッドをキャプチャ
- インターフェースの満足度をリンク、または推測信頼度をマーク
- 設定に従って生成ファイルを処理する
