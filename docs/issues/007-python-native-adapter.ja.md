# ネイティブアダプター：Python

ラベル：`adapter`、`python`、`priority:P2`、`status:ready`

## 問題点

Pythonは動的です。役立つアダプターは、AST構造と最善の努力による型情報を組み合わせ、動的呼び出しを確実であるかのように装うことを避けなければなりません。

## 候補バックエンド

- Python `ast`。
- コンクリート構文とメタデータのためのLibCST。
- 型/シンボル解決のためのPyrightまたはJedi。
- `pyproject.toml`の検出。

## 必要な抽出項目

- パッケージとモジュール。
- クラスと基本クラス。
- メソッド、プロパティ、データクラスのフィールド、`self`の代入。
- インポートと相対インポート。
- 最善の努力による呼び出しとコンストラクタ呼び出し。
- 動的エッジの信頼度メタデータ。

## 受け入れ基準

- プレーンなPythonパッケージのルートで動作する。
- 可能な限りデータクラスやattrs/pydanticスタイルのフィールドをキャプチャする。
- 解決できない動的エッジに対して信頼度を出力する。
- 構文やバージョンの不一致でクラッシュしない；診断を報告する。
