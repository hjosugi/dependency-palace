# ネイティブアダプター：C# / .NET

ラベル：`adapter`、`csharp`、`dotnet`、`priority:P2`、`status:ready`

## 問題点

C#プロジェクトには、名前空間、アセンブリ、部分クラス、ジェネリック、LINQを多用した呼び出し、インターフェース、レコード、属性に関するRoslynレベルの意味情報が必要です。

## 候補バックエンド

- Roslyn解析器実行ファイル。
- `dotnet`のソリューション/プロジェクトの検出。
- オプションのNDependエクスポート変換器。

## 必須抽出項目

- ソリューション、プロジェクト、アセンブリ、名前空間。
- クラス、インターフェース、レコード、構造体、列挙型。
- フィールド、プロパティ、メソッド、コンストラクター。
- 基底クラスと実装されたインターフェース。
- メソッド呼び出し、オブジェクト生成、依存性注入コンストラクタのパラメーター。
- テストプロジェクトの分類。

## 受け入れ基準

- `.sln`および`.csproj`で動作すること。
- 部分クラスを処理できること。
- 完全修飾型IDを出力すること。
- プロパティをフィールドと別にキャプチャすること。
- DIコンストラクタの依存関係を`uses`または`creates`として`via`とリンクすること。
