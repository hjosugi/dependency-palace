# ネイティブアダプター：C および C++

ラベル: `adapter`、`c`、`cpp`、`priority:P2`、`status:ready`

## 問題点

C/C++の構造は、翻訳単位、ヘッダー、マクロ、テンプレート、名前空間、ビルドフラグに依存します。正確な抽出にはコンパイラツールが必要です。

## 候補バックエンド

- `clangd`インデックス。
- `libclang`。
- `compile_commands.json`。
- CMake/Bazelの検出。

## 必要な抽出内容

- 翻訳単位とヘッダー。
- 名前空間。
- クラス、構造体、列挙型、共用体。
- フィールド、メソッド、コンストラクター、デストラクター。
- 継承。
- インクルード。
- 利用可能な場合の関数呼び出しとオブジェクト生成。
- マクロ生成のシンボル診断。

## 受け入れ基準

- `compile_commands.json`が存在する場合はそれを使用。
- コンパイルデータベースがない場合はヘッダー/ソースのスキャンにフォールバック。
- テンプレート名を安定して出力。
- スキップされた翻訳単位とその理由を報告。
