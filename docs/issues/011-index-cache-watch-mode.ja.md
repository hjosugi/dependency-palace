# 増分インデックス、キャッシュ、ウォッチモード

ラベル: `パフォーマンス`、`インデックス作成`、`開発者体験`、`優先度:P1`、`ステータス:準備完了`

## 問題点

大規模なリポジトリは、すべての実行時に完全に再スキャンできません。ネイティブアダプターには、永続的なキャッシュと増分更新が必要です。

## 範囲

- ファイル内容のハッシュ化。
- アダプターのバージョンハッシュ化。
- ファイルごとの抽出キャッシュ。
- ファイル間のシンボル解決キャッシュ。
- ウォッチモード。
- 進行状況とキャンセル。
- 大規模なグラフのチャンク化。

## 受け入れ基準

- 変更のないリポジトリで再スキャンを実行しても、キャッシュされた抽出結果を再利用。
- 1つのファイルを編集しただけで、影響を受けるファイルとシンボルのエッジのみが無効化。
- スキャンの進行状況が見える。
- キャッシュを無効化およびクリアできる。
- 大きな出力をストリーミングまたはチャンク化できる。
