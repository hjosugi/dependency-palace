# ビューアのワークフロー：スキャン、開く、更新

ラベル：`viewer`、`workflow`、`developer-experience`、`priority:P1`、`status:ready`

## 問題点

ユーザーは永遠にスキャンした後に手動でJSONを読み込む必要がありません。ビューアはスムーズなローカルワークフローをサポートすべきです。

## 範囲

- デフォルトのスキャン出力パス。
- ビューアはURLまたはローカル開発エンドポイントからグラフJSONを読み込める。
- スキャンやウォッチの更新後に自動的にグラフをリフレッシュ。
- UIにアダプタの診断情報を表示。
- 詳細パネルにソースファイルのパスとシンボル範囲を表示。

## 受け入れ基準

- `npm run scan -- ./repo` はデフォルトの場所に書き込みます。
- `npm run dev` は最新のグラフが存在すれば自動的に開きます。
- ウォッチモードは、可能な限り選択されたノードを失わずにビューアをリフレッシュします。
- 診断パネルはスキップされたファイルと未解決のエッジを表示します。
