# 実世界の例コーパス

ラベル: `examples`、`fixtures`、`research`、`priority:P1`、`status:ready`

## 問題点

生成された例はスケールや予測可能なカバレッジに役立ちますが、実際のコードには命名規則、レイヤー構造、生成コード、テスト、ビルドフォルダ、依存関係の奇妙さなど、合成データではカバーできない要素があります。

## 目標

スキャナーとビューアの動作を網羅する、キュレーションされた実世界の例コーパスを構築する。

## 範囲

- 小規模なオープンソースのHaskellフィクスチャリポジトリまたは抜粋を追加。
- 小規模なオープンソースのJavaフィクスチャリポジトリまたは抜粋を追加。
- 一つの多言語サービスフィクスチャを追加。
- フィクスチャのライセンスが互換性を持つようにする。
- ソースの抜粋または生成されたグラフスナップショットを保存。
- 各フィクスチャがビューアでどのように見えるべきかをドキュメント化。

## 受け入れ基準

- 少なくとも一つのHaskellと一つのJavaの実世界フィクスチャをローカルでスキャンできる。
- フィクスチャの出力がコミット済みまたはスクリプトで再現可能。
- ドキュメントにソース/ライセンスと期待されるセマンティックハイライトを記載。
- ビジュアル検証で少なくとも一つの実世界のグラフをロードできる。
