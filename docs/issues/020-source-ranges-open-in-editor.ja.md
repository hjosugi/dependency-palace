# ソース範囲とエディタで開くワークフロー

ラベル: `viewer`、`scanner`、`developer-experience`、`priority:P1`、`status:ready`

## 問題点

ビューアはシンボルを表示しますが、まだユーザーがソースにジャンプできるようになっていません。コード理解のためには、3Dモデルを実際のファイルや範囲に接続する必要があります。

## 目標

アダプターからのソース位置のメタデータをビューアに引き継ぎ、エディタで開くワークフローを公開します。

## 範囲

- スキーマを拡張し、ソースファイルのパスとシンボル範囲を追加。
- アダプターが提供できるメンバーごとの範囲を追加。
- 選択されたパネルにソースファイル／範囲を表示。
- パスのコピーとオプションのエディタURLコマンドを追加。
- 可能な限りパスをスキャンルートに対して相対的に保持。

## 受け入れ基準

- スキャナーがHaskellおよびJavaのフィクスチャに対してソースメタデータを出力。
- 選択されたパネルにファイルパスと行範囲が表示される。
- ユーザーがソース位置をコピーできる。
- ソースメタデータが欠落している場合も適切に処理される。
