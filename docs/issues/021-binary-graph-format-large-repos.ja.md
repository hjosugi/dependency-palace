# 大規模リポジトリ向けバイナリグラフフォーマット

ラベル: `パフォーマンス`, `グラフフォーマット`, `大規模リポジトリ`, `優先度:P1`, `ステータス:準備完了`

## 問題点

大規模なJSONグラフは検査が容易ですが、解析や転送には負荷がかかります。ストレステストの例ではすでに数メガバイトのペイロードに達しています。

## 目標

大規模リポジトリ向けのオプションのコンパクトなグラフフォーマットを設計・実装する。

## 範囲

- JSONをポータブルな基準として維持する。
- 大規模に生成されたグラフ用にバイナリまたはチャンク化されたフォーマットを追加する。
- 文字列テーブル、ノード、リンク、メンバー、メタデータを分離する。
- ストリーミングまたは段階的な読み込みをサポートする。
- 解析時間、転送サイズ、メモリ使用量を測定する。

## 受け入れ基準

- JSONグラフは引き続き読み込めること。
- 大きなバイナリ/チャンク化グラフは、ベンチマークで同等のJSONよりも高速に読み込めること。
- フォーマットのドキュメントが存在すること。
- CLIはJSONとコンパクトフォーマットの両方を出力できること。
