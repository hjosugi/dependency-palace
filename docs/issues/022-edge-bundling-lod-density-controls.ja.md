# エッジバンドル、LOD、密度コントロール

ラベル: `レンダリング`、`パフォーマンス`、`UX`、`優先度:P1`、`状態:準備完了`

## 問題点

密なグラフは、レンダリングが高速であっても読み取りにくくなる。ユーザーは意味を保持したまま視覚的な密度を調整できるコントロールを必要としている。

## 目標

大規模マップに対してエッジバンドル、詳細レベル（LOD）の挙動、密度コントロールを追加する。

## 範囲

- Mapビューでパッケージ間のエッジをバンドル。
- カメラ距離に応じて低優先度のエッジをフェード。
- エッジ密度のプリセットを追加。
- 選択されたノードの直接エッジを表示。
- 弱いインポートよりも意味的なエッジの種類を優先。
- エッジが非表示またはバンドルされている場合を表示。

## 受け入れ基準

- ストレスグラフのMapビューはデフォルトのズームで読みやすい。
- ノードを選択すると、そのノードの直接的な意味的エッジが復元される。
- 密度コントロールは、可能な限りグラフ全体を再構築せずに更新される。
- ビジュアル検証は少なくとも一つの密なグラフをカバーしている。
