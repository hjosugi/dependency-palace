## GitHub作成

推奨タイトル形式：

```text
[DP-014] 起動とサンプルペイロードのパフォーマンス
```

推奨ラベル：

- `priority:P0`、`priority:P1`、または `priority:P2`
- `performance`、`viewer`、`adapters`、`haskell`、`java`、`testing` などのエリアラベル
- `status:ready`

イシューのファイルは意図的に自己完結型にしてあり、後でGitHubのイシューに貼り付けたり、スクリプトで同期したりできるようになっています。

## 同期コマンド

```bash
npm run issues:dry-run
npm run issues:sync
```

同期スクリプトは `[DP-###]` のタイトルプレフィックスによって既存のイシューと一致させ、不足しているラベルやイシューを作成します。
